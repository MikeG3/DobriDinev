# Dobri Dinev – Historical Archive
This repository contains the source code for a public historical website dedicated to **Dobri Dinev**, a Bulgarian marathon swimmer, coach, and sports organizer.

The purpose of this project is to:
- Preserve historical records, media, and documentation
- Provide a neutral, well-sourced public reference
- Serve as a supporting archive for researchers and Wikipedia editors

## Contents
- Biographical overview
- Records and achievements
- Awards and honors
- Newspaper coverage and media
- Video interviews and press footage
- Source references

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages for hosting

## Editorial Principles
- Neutral, factual tone
- Clear sourcing
- No original research
- Historical documentation focus

## Status
This project is actively maintained and expanded as additional archival material is digitized and verified.
